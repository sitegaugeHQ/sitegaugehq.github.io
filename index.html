Run one from code

Every tool is one HTTP call. This asks what three websites are built with and returns the rows as JSON.

curl -s -X POST \
 "https://api.apify.com/v2/acts/sitegauge~website-technology-detector/run-sync-get-dataset-items" \
 -H "Authorization: Bearer $APIFY_TOKEN" \
 -H "Content-Type: application/json" \
 -d '{"websites": ["apify.com", "crawlee.dev", "wordpress.org"]}'

What these tools will not do

  • Try to get around a block or a login. Robots.txt is respected by default.
  • Collect names, email addresses or other personal data.
  • Guess. Every finding comes with the signal it was recognised by.
  • Charge for a website the technology detector could not read.
